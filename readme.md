## Description 

Lumina Creative is a practice website that demonstrates principles of minimalist design. It serves as a portfolio to showcase creative projects, with a particular emphasis on clean layouts and intuitive navigation. The website is structured with distinct sections for home, about, and contact, providing a complete yet simple online presence for creative endeavors.

--- 

## Features

- **Minimalist Design:** A clean and uncluttered user interface that highlights the content.
- **Responsive Navigation:** A header with a logo and navigation links (Home, About, Contact) that adapts to different screen sizes.
- **Engaging Hero Section:** A prominent section with a compelling headline to capture user attention.
- **Visual Portfolio Gallery:** A grid-based gallery showcasing images with a functional lightbox for enlarged viewing.
- **About Page:** Details about the company's services and team members.
- **Contact Form:** A functional form for users to submit inquiries.
- **External Libraries:** Utilizes `lightbox2` for image galleries and `Font Awesome` for icons.
- **Google Fonts Integration:** Employs 'Open Sans', 'Oxanium', and 'Quantico' for a modern typography.

--- 

## Tech Stack

- **HTML5:** For structuring the web content.
- **CSS3:** For styling and layout, including responsive design.
- **JavaScript:** Used indirectly via external libraries for enhanced interactivity (e.g., Lightbox).
- **External Libraries:**
    - [Lightbox2] For image pop-up functionality.
    - [Font Awesome] For icons.
    - [jQuery] As a dependency for Lightbox.
- **Google Fonts:** For typography.
